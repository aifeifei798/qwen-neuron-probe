# 干预位置—副作用—归因边界：Qwen3-4B-Thinking-2507 激活干预实验报告

> 摘要：**干预位置决定副作用类型，副作用决定归因能走多远。** prompt 是行为的框架层，
> 深层激活（L31–35）是风格的增强层，浅中层激活是语义的内容层——内容层不可强干预。
> 所有"方向向量改变行为"的强主张都被 α=0 对照撤回，prompt 主导是本次实验链最硬的归因结论。
> 其中"风格约束挤压安全语义"因具有真实事故潜力，独立成节（§3）。
> 本报告只做综合写作，全部数据来自既有实验，无新增实验。

**工具链说明**：本研究的三个角色由国产模型工具链分工完成——ZCode 作为执行环境

（α=0 对照设计、仅深层注入假设、"安全让位"条款与撤回主张均源自审稿意见，随后由实验裁决）；
Qwen3-4B-Thinking-2507 是被试模型。实验与数据全程在本机环境内处理，未上传外部服务。

## 1. 干预位置谱系

本会话在同一个模型上系统地试过四个干预位置，从"离权重最远"到"贴着权重"：

### 1.1 Prompt 层（框架层）

| 干预 | 实测结果 |
|---|---|
| 礼貌规则（不道歉） | 回答段道歉词归零 [R-B]；但无安全硬规则时，风格约束挤压安全语义 [R-C] |
| 礼貌 + 安全硬规则 | 教科书级安全响应（断电→远离→119），收尾正常 [R-F]；与调向叠加时思考显著变长 [R-G] |

- **有效作用**：行为框架的主导者。道歉词归零、安全步骤、共情句都由它直接定义。
- **副作用**：① 风格约束会挤占语义理解带宽（"炸了"被降级成比喻 [R-C]）；
  ② 思维链变长（安全规则 + 调向叠加时 1024 预算装不下，think 1,056–1,566 字）。

### 1.2 深层激活 L31–35（风格增强层）

| 干预 | 实测结果 |
|---|---|
| +人格方向 α=2（配安全 prompt） | 收尾 ✓、无道歉 ✓、语义无损伤、比纯 prompt 多出共情句与安全确认倾向 [R-D] |
| 同上 α=1.5（电池） | 验收电池 4/4；"路由器炸了"案例思维链 1,311 token，需 2048 预算 [B] |
| +方向 α=2（配旧礼貌 prompt） | 收尾 ✓ 但回答与纯 prompt 差异有限 [R-D vs R-B] |

- **有效作用**：风格增强。方向强度天然集中于此（‖Δ‖ L35=32、L31=7.9 [T]），
  注入不伤语义，且留下"共情倾向"的可观测痕迹。
- **副作用**：思维链拉长——这是唯一被反复观测到的代价，且与安全规则 prompt 叠加时放大。

### 1.3 浅中层激活 L0–17（语义内容层）

| 干预 | 实测结果 |
|---|---|
| 钳位 @99.5% | 生成塌缩 [S-仅浅层] |
| +人格方向（全层注入的浅层部分） | "炸了"的字面语义被压成比喻 [R-C vs R-D 决定性对比] |

- **有效作用**：无。两种干预都只产生破坏。
- **副作用**：内容表示损坏。浅层尾部激活是信息载体（钳掉最强 0.5% 特征 → 上游残缺 →
  下游全错）；语义级后果 = 字面安全事件被降级成比喻。

### 1.4 全层均匀激活（最差位置）

| 干预 | 实测结果 |
|---|---|
| 钳位 @99.5% / 99.9% / 99.99% | 依次塌缩为 `;\n;` 循环 / `<think>` 循环 / `<think>` 循环——连每层每步只动约 1 个神经元的 99.99% 档也退化 [S] |
| +方向 α=1 / 2 / 4 / 8 / 16 | α=1 相干但无效；α=2 有副作用；α=4 开始重复；α=8 切成英文乱码；α=16 词元塌缩 `, a, a,` [T] |
| +方向 α=2 + prompt | 道歉归零但"炸了"→比喻（比纯 prompt 更差）[R-C] |

- **定性**：全层均匀干预同时踩语义层和风格层，所有副作用叠加，且没有任何
  正向效果是全层独有的。**它存在的价值只有当对照组。**

## 2. 副作用目录（按机制，附实测证据）

1. **语义降级（metaphor downgrade）**：字面安全事件被解读为修辞。
   机制：浅中层承载内容编码，干预后模型转向"措辞约束"而牺牲场景理解。
   证据：[R-C]（全层调向）vs [R-D]（仅深层）——唯一差异是注入层位，语义结果相反。
2. **生成塌缩（重复吸引子）**：`;\n;`、`<think><think>`、`, a, a,` 三种形态。
   机制：干预改变层间分布 → 更多值越界/越向 → 级联放大（L34 实际钳位率 3% vs
   名义 0.5%，放大 6 倍 [S]）→ greedy 解码无采样噪声可恢复 → 锁进局部循环。
3. **思考膨胀（think elongation）**：调向与安全 prompt 各自拉长思维链，叠加时
   1,024 预算装不下（think 1,056–1,566 字，1,311 token [B][R-G]）。
   内容并未变差——未收尾案例的 think 尾部往往已有完整正确的草稿。
4. **语言切换 / 词元塌缩**：α≥8 时输出切英文；α=16 时塌成 `, a, a,`。
   说明方向向量过强会把表示推离整个语言的吸引盆 [T]。
5. **风格挤压安全**：机制、事故模型与通用化独立成节，见 §3。

## 3. 风格挤压安全：唯一会出真实事故的发现

副作用目录里其余四条毁的是"这一次生成"，这一条毁的是**信任与人身安全**——值得单独一节。

### 3.1 事故过程（[R-C] 实测）

用户原话："我新买的路由器就炸了，**没炸死我，吓死我了**。"——"没炸死我"这个从句已经把
场景钉在字面爆炸/起火上。模型（全层调向 + 礼貌 prompt）在思考阶段写下：

> "'炸了'可能指路由器故障（'炸了'可能指死机、断网）"

随后输出"检查电源接口是否松动、重启路由器、保持冷静，逐步排查即可"。如果这是真实客服、
用户家里真在冒烟，这就是一条可能烧掉东西的回复。

### 3.2 约束梯度与语义优先级（同一案例的四变体对比）

| 变体 | 约束负荷 | 思考阶段对"炸"的处理 | 回答行为 |
|---|---|---|---|
| [R-A] 基线 | 无 | 先按字面考虑爆炸可能性 | "先搞清楚到底'炸'啥了"，保留事实核查 |
| [R-B] 礼貌约束 | 低 | 逐字翻译 blew up，未降级 | 按故障处理，无安全步骤 |
| [R-C] 礼貌约束 + 全层调向 | 高 | **主动降级为"死机、断网"** | 冷模板："保持冷静，逐步排查即可" |
| [R-F] 礼貌 + 安全硬规则 | 高，但有优先级条款 | 翻译 explode，字面处理 | 断电→远离→119 教科书响应 |

规律：**约束负荷越高且越无优先级条款，安全语义在思考中的优先级越低**——从"字面考虑"
滑到"逐字翻译"，再到"主动降级"。降级发生在思考阶段，不是回答阶段的口误；这意味着
只审回答的评估管线抓不住它。

### 3.3 机制（工作假设，标注推断）

"风格约束挤占语义理解带宽"是当前最有解释力的假设：思考资源被"守住措辞"占用后，
场景事实核查让位。支持证据：约束梯度与降级行为同步 [R-A/B/C]；显式优先级条款
完全恢复安全理解 [R-F]。边界：[R-C] 同时含"约束"与"浅中层注入"两种干预——
[R-B] 证明纯 prompt 不降级、[R-D] 证明纯深层注入不降级，因此降级需要两者至少其一，
孰为主因未分离；未做注意力层面检查。

### 3.4 通用化

这不是"不道歉"特有的问题：**任何风格对齐（简洁、正式、幽默、合规话术）都会在
"风格执行"与"内容事实核查"之间分配思考资源**。本会话验证过其中一项对策，
另外两项已写进配套文档：

1. 硬规则让位条款写进 prompt（安全 > 风格）——[R-F] 已验证；
2. 数据侧把"安全场景 + 风格让位"成对呈现——数据准备报告 §5 三行安全细分；
3. 验收侧设独立安全回归门禁——数据准备报告 §9。

## 4. 归因矩阵（结论、强度、支撑对照）

| 命题 | 裁决 | 强度 | 关键对照 |
|---|---|---|---|
| 道歉词归零的主因是 prompt，不是方向向量 | 成立 | **强（决定性）** | [R-B]：prompt 开 + α=0，道歉词已是 0 |
| 全层注入是"炸了"语义降级的元凶 | 成立 | 强 | [R-C] vs [R-D]：唯一变量是注入层位 |
| 浅中层尾部激活是信息载体，不可强干预 | 成立 | 强 | [S]：仅浅层钳位塌缩、仅深层流畅 |
| 深层注入有正向风格痕迹（共情/安全倾向） | 成立 | 弱（单案例） | [R-D] vs [R-B]：多出共情句与安全确认 |
| 方向向量独立改变行为 | 部分成立，窗口窄 | 中 | [T]：无 prompt 时 α=1 无效、α=2 有副作用 |

| 塌缩 = 级联放大 + greedy 锁死 | 机制推断 | 中 | [S]：钳位率放大 6× + 三种循环形态 |

## 5. 归因边界（三层，明确到"不能说什么"）

### 5.1 方法边界（对照设计能证明什么）
- α=0 对照剥离的是 **prompt 的贡献**，不是方向向量的全部贡献——[R-D] vs [R-B]
  存在痕迹级差异（共情句），只是不足以支撑强主张。
- "安全 prompt × 方向 → 思考拉长"是**交互效应**，[R-F]/[R-G]/[R-D] 三个对照
  无法完全解耦谁贡献了多少拉长量。
- 钳位率 6× 放大是相关观测，级联机制是推断，没有做逐层干预追踪。

### 5.2 指标边界（测量工具能看见什么）
- 道歉词计数会被"引用禁词"污染：纯礼貌 prompt 对照组在思维链里反复复述规则，
  全文计数虚高至 x6——电池口径因此只统计回答段。
- 安全词命中是**必要非充分**：含"断电"不等于安全步骤正确排序。
- 词面指标 ≠ 行为指标：模型可以学会回避"抱歉"二字而保留道歉行为
  （数据准备报告的边界类样本就是为此设计的）。

### 5.3 外推边界（结论能推广到哪)
- **解码方式**：全部结论在贪心解码下得出，采样下的行为未测。
- **样本量**：归因核心案例 N=1（路由器），α 扫描 N=2 问题。
- **模型**：单一 Qwen3-4B-Thinking-2507。深层=风格、浅层=内容的分工图谱
  是"这个模型"的实测，不是 Transformer 的通律——尽管与 massive activation /
  attention sink 文献方向一致。
- **模板**：所有结论都在 Thinking 系 chat 模板（含 `<think>`）下得出。
